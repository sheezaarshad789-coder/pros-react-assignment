# pros-react-assignment

A clean and responsive product card UI built with React, designed to showcase product details, pricing, and call-to-action elements in a modern e-commerce style.

## Features
- Responsive product card layout
- Modern UI design for ecommerce products
- Product image, title, price, and action buttons
- Built with React and Vite

## Tech Stack
- React
- Vite
- CSS

## Run locally
```bash
npm install
npm run dev
```
